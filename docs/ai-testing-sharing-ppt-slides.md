## 第 3 页 — 四个痛点

### 幻灯片文字

```
测试工作的四个「时间黑洞」

① 测试设计慢        需求 → Excel 用例，常常半天起
② 自动化起步慢      登录、token、定位、框架搭建
③ 回归成本高        版本一多，手工点不过来
④ 协作摩擦大        缺截图、缺日志、缺结构化证据
```

### 演讲备注

问一句「大家有没有同感」，等 1 秒。四个痛点里至少一个会戳中每个人。产品可能更懂 ①④，开发更懂 ②，测试全中。引出：AI 不是替代测试，是压缩重复劳动。

## 第 14 页 — TestSprite 试点

### 幻灯片文字

```
MCP 试点：TestSprite

收获

## 第 15 页 — 四个坑

### 幻灯片文字

```
我踩过的四个坑

① 幻觉        编造接口字段 / 页面选择器
              → 让它先读现有文件，改完必跑 pytest

              → 工具报告 + pytest 交叉验证

④ 泄密风险    账号密码进 prompt
              → .env + Jenkins Credentials
```

## 第 16 页 — 四条原则

### 幻灯片文字

```
可复制的四条原则

1. AI 写初稿，人 sign-off
2. 给足上下文（仓库结构 + 接口文档 + 现有代码）
3. 小步提交，立即运行
