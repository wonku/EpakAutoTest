# 固定用例格式

与仓库近期 CRM 用例 Excel 对齐（如 `CRM支持创建新版询价单_TestCases.xlsx`）。

## 总表 / 模块表表头（顺序不可改）

| # | 列名 | 说明 |
|---|------|------|
| 1 | 用例ID | 模块前缀 + 序号 |
| 2 | 模块 | `序号-名称` |
| 3 | 优先级 | P0 / P1 / P2 |
| 4 | 场景 | 可执行标题 |
| 5 | 前置条件 | 环境与数据 |
| 6 | 测试步骤 | 多行编号 |
| 7 | 预期结果 | 可判定 |
| 8 | 实际结果 | 空 |
| 9 | 备注 | 需求摘录/待确认 |
| 10 | 用例状态 | 空 + 下拉 |
| 11 | 是否阻塞 | 是 / 否 |
| 12 | 首轮必测 | 是 / 否 |

> 注意：部分旧脚本列顺序为「是否阻塞/首轮必测」靠前。**本 Skill 以最新询价单 Excel 为准**：阻塞与首轮在末尾两列。

## 需求追溯 Sheet

| 行 | A | B |
|----|---|---|
| 1 | 需求文档 | 飞书标题 |
| 2 | 飞书地址 | 完整 URL |
| 3 | 功能范围 | 模块摘要 |
| 4 | 用例状态 | PASS / FAIL / BLOCK / N/A |
| 5 | 统计 | `合计N条；阻塞x条；首轮必测y条；P0=z条` |

## 覆盖检查 Sheet

表头：`需求点 | 覆盖情况 | 对应用例`

- 覆盖情况：已覆盖 / 部分覆盖 / 待确认  
- 对应用例：`IQ-001~005` 或枚举 ID  

## 阻塞场景清单 Sheet

表头：`用例ID | 模块 | 场景 | 优先级 | 阻塞说明 | 失败影响`

## 优先级说明 Sheet

固定写入：

| 字段 | 定义 |
|------|------|
| P0 | 核心功能/主流程/数据正确性；必须首轮执行 |
| P1 | 重要分支、权限、筛选、补偿 |
| P2 | 边界、UI、非关键异常；回归轮次 |
| 是否阻塞=是 | 失败则后续模块测试无意义 |
| 首轮必测=是 | 第一遍必须执行；见「首轮冒烟」 |
| 用例状态 | PASS/FAIL/BLOCK/N/A；BLOCK=环境/依赖阻塞 |

## 单条用例示例

| 字段 | 值 |
|------|-----|
| 用例ID | IQ-003 |
| 模块 | 1-询价记录Tab |
| 优先级 | P0 |
| 场景 | 有权限用户打开询价记录列表可见新建入口 |
| 前置条件 | 测试环境；账号具备询价菜单与新建权限 |
| 测试步骤 | 1. 登录 CRM\n2. 进入询价记录\n3. 观察列表工具栏 |
| 预期结果 | 展示「新建询价」入口；点击可打开创建流程 |
| 实际结果 | （空） |
| 备注 | 对应 PRD「入口与权限」 |
| 用例状态 | （空） |
| 是否阻塞 | 是 |
| 首轮必测 | 是 |
